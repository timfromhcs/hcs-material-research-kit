# Code of Conduct

## Our commitment

We want this project to be a place where people can contribute rigorous scientific software
without harassment, gatekeeping or hostility. We welcome contributors of any background and
experience level.

## Expected behaviour

- Discuss ideas and code, not people.
- Assume good faith, but ask for evidence when a claim is scientific.
- Give and accept specific, actionable review comments.
- Respect that "I don't know" and "this is not validated" are acceptable answers.
- Credit sources, datasets and prior work.

## Unacceptable behaviour

- Harassment, insults, discriminatory language, or unwanted attention.
- Presenting fabricated results, plagiarised code or unlicensed data as your own.
- Pressuring maintainers to merge unvalidated claims or to remove honest limitations.
- Publishing another person's private material structures, data or credentials.

## Scope

This code applies to issues, pull requests, discussions and any space where the project is
represented.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may temporarily or
permanently restrict participation. Reports are handled confidentially.
