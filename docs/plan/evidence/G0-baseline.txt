Defects found at G0 (fixed during this release):
1. `npm run test:python` is broken on Windows; the documented command in
   README.md does not work on the reference machine.
2. `scripts/make-reference-fixtures.ts` embeds a random structure_id and a
   timestamp, so the CI drift check `git diff --exit-code tests/fixtures/reference`
   was guaranteed to fail on the first run.
3. `npx tsx` is used by CI but tsx is not a dependency (unpinned download).
4. README.md states inconsistent test counts (99/5/32 vs 121/8/36).
5. `npm run fmt:check` does not pass on the baseline tree (prettier drift across
   pre-existing files); it is therefore not part of the release gate. A
   repo-wide formatting pass is deferred to v0.3.0 with its own review.

Baseline is GREEN for typecheck, TypeScript, Rust, build and E2E. The two
documentation defects above made it impossible to reproduce the documented
workflow on Windows, which is why they are release blockers, not cosmetics.
